# 教員用・学生用画面の使い方

## 全体フロー

```text
教員が教材を入力
  ↓
小テスト生成
  ↓
学生用URLを共有
  ↓
学生が回答・採点結果を確認
  ↓
教員が回答結果と講義分析を確認
```

ログイン画面やロール管理はありません。表示内容と操作の目的を分かりやすくするために、教員用と学生用のHTMLを分けています。

## 入口画面

`index.html`には次の2つのリンクがあります。

- 教員用：`teacher.html`
- 学生用：`student.html`

通常、学生には入口画面ではなく、教員画面で作成した`quiz_id`付きURLを共有します。

## 教員用画面

### 小テストを作成する

1. 講義タイトルと問題数を入力する。
2. 「テキスト入力」または「PDFアップロード」を選択する。
3. 教材を入力する。
4. 「小テストを生成」を押す。

PDFは5MB以下で、文字を選択できるものを使用してください。画像だけのPDFはテキストを抽出できません。

### 学生へ共有する

生成後、次の形式の学生用URLが表示されます。

```text
https://AMPLIFY_DOMAIN/student.html?quiz_id=quiz_xxxxxxxxxxxx
```

「URLをコピー」を押し、講義中に学生へ配布します。「学生画面を確認」を押すと、別タブで実際の回答画面を確認できます。

### 回答を分析する

生成した`quiz_id`は、回答分析欄へ自動入力されます。「結果を取得・更新」を押すと、次の情報を表示します。

- 回答者数
- 平均点と平均正答率
- 問題ごとの正答率
- Bedrockによる講義分析
- 学生別の得点

結果を更新するたびに、現在のLambda実装ではBedrockによる分析処理も実行されます。

## 学生用画面

`quiz_id`付きURLから開くと、小テストが自動的に読み込まれます。URLに`quiz_id`がない場合は、教員から伝えられた値を入力して読み込みます。

1. 学生IDを入力する。名前は任意。
2. すべての問題に回答する。
3. 「回答を送信」を押す。
4. 得点、各問題の正誤、正解、解説を確認する。

回答前には正解と解説を表示しません。回答送信後は入力欄をロックします。別の小テストを読み込むと回答画面がリセットされます。

## 将来のPowerPoint統合

教員用画面の教材入力部分を共通入口として利用できます。チーム側の実装を統合するときは、同じPDFまたは抽出テキストを次の2つへ渡します。

```text
共通教材入力
  ├─ 小テスト生成
  └─ PowerPoint生成
```

学生用画面は小テスト回答専用のまま維持できます。
